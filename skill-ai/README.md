# Thư mục Skill AI

Thư mục này `skill-ai/` được sử dụng riêng biệt cho việc ghi chú, lên ý tưởng, và lập kế hoạch logic trong quá trình Agent hỗ trợ dự án **Course Store**. 

**Quy tắc chung:**
1. Tất cả tài liệu trong này chỉ đóng vai trò "Nháp" (Draft) và phân tích hướng dẫn (Guidelines) chứ không phải code thực tế chạy trên Production.
2. Thư mục này đã được cấu hình loại trừ (Bỏ qua) khỏi `Git` (khai báo trong `.gitignore` là `/skill-ai`). Do đó mọi thứ cập nhật trong đây sẽ không bị đẩy lên mã nguồn chung trên remote host.
3. Khi ghi chú logic cho bất cứ file/hệ thống nào, chúng ta sẽ nêu rõ đường dẫn tệp gốc (ví dụ: `[modules/Teacher/src/Http/Controllers/Clients/StudentQuizController.php]`) để dễ đối soát.

---

*Bắt đầu từ thời điểm này, mọi ý tưởng cần nháp hoặc code logic phức tạp cần phân tích trước khi viết sẽ được đẩy vào các file .md trong thư mục này.*
